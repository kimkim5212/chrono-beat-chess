CHRONO-BEAT CHESS - プレイ説明書

■ ゲーム概要・機能紹介
チェスと音楽ゲーム（リズムゲーム）を融合させたリアルタイム・ストラテジーゲームである。
通常のチェスのようなターン制ではなく、リズムゲームによってアクションポイント（AP）を稼ぎ、リアルタイムに駒を動かして戦う。

・リズムによるAP獲得とコンボシステム
画面右側のレーンに降ってくるノーツに合わせて入力を行うことでAPが溜まる。
連続で成功（コンボ）させると、20コンボごとに獲得APにボーナス倍率が加算される。

・リアルタイムで進行する敵AI
敵の駒にはチャージゲージがあり、時間経過で満タンになった駒から自動的にプレイヤーの陣地へ向かって進行、または攻撃してくる。

・カスタマイズ可能な難易度
タイトル画面にて、ゲームのテンポ（BPM）を固定値、またはカスタム値（40〜300）から自由に設定できる。
また、敵のゲージが溜まる速度（敵の強さ）を「弱（0.8倍）」「普（1.0倍）」「強（1.2倍）」の3段階から選択可能である。

■ 操作説明
・リズムゲーム（AP獲得）
[スペースキー]
ノーツが画面下部の判定ラインに重なるタイミングで押す。
判定（Perfect/Good）に応じてAPを獲得する。Missをするとコンボが0にリセットされる。

・チェス盤面操作
[マウスのドラッグ＆ドロップ]
動かしたい自分の駒を左クリックで掴み、ハイライトされた移動先のマスへドロップする。
駒の種類（ポーン、ナイト、クイーンなど）に応じて一定のAPを消費する。APが足りない場合は元の位置に戻される。

・システム操作
[Escキー]
ゲームの一時停止（ポーズ画面の表示）。
ポーズメニューから「ゲーム再開」「最初からやり直す」「タイトルへ戻る」を選択できる。

・敗北条件：自分のキングを取られる
